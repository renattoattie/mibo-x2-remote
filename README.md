# Mibo Controle Local

Controle remoto Android para Mibo X2 pela rede local, sem depuração durante o uso. Inclui o receptor instalado no Mibo e o controle instalado no celular.

## Instalação e uso

Consulte [INSTALAR.md](INSTALAR.md) para instruções completas, pareamento, segurança, limitações e compilação. Baixe os dois arquivos APK deste repositório: instale o receptor no Mibo e o controle no celular. Ative o serviço de acessibilidade do receptor e gere um código para parear cada celular.

A versão 0.2 aceita até 16 celulares autorizados e oito conexões simultâneas. O sistema foi experimentado no Mibo X2; compatibilidade pode variar entre aplicativos e outros aparelhos.
